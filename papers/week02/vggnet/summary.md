# Week 2-1. VGGNet

**Very Deep Convolutional Networks for Large-Scale Image Recognition**
Karen Simonyan, Andrew Zisserman — *arXiv 2014 / ICLR*, 2015
원문: [`paper_link.md`](./paper_link.md) 참고

## 1. 배경 및 문제의식

AlexNet(2012) 이후 성능을 높이려는 시도들은 주로 첫 층의 큰 커널(11×11)과 큰 stride를 줄이거나(ZFNet, OverFeat),
여러 스케일로 이미지를 학습·평가하는 방향이었다. VGG 논문은 다른 질문을 던진다.

> 다른 설정은 모두 고정하고 **깊이(depth)만** 늘리면 성능이 얼마나 오르는가?

이를 위해 모든 합성곱을 **3×3** 으로 통일해 깊이를 안정적으로 늘릴 수 있게 했고, 11층에서 19층까지 체계적으로 비교했다.
"VGG"는 저자들이 속한 옥스퍼드 Visual Geometry Group에서 왔다. ILSVRC-2014에서 분류 2위, 위치 추정(localisation) 1위를 기록했다.

## 2. 핵심 아이디어

1. **작은 필터(3×3)만 쌓기**: 3×3은 좌/우/상/하/중심 개념을 담을 수 있는 가장 작은 크기. stride 1, padding 1로 공간 해상도를 보존하고, 해상도 축소는 2×2 max-pool(stride 2)만 담당한다.
2. **같은 수용 영역, 더 적은 파라미터**
   - 3×3 conv 2개 = 5×5 conv 1개, 3개 = 7×7 conv 1개와 같은 수용 영역.
   - 채널 수를 C라 할 때 파라미터: 7×7 한 층은 `49C²`, 3×3 세 층은 `3 × 9C² = 27C²` (약 45% 절감).
   - ReLU가 1번 → 3번으로 늘어 결정 함수가 더 판별적(discriminative)이 된다.
3. **1×1 conv (구성 C)**: 수용 영역은 바꾸지 않고 비선형성만 추가 (Network-in-Network에서 영감).
4. **깊이의 체계적 비교**: 구성 A~E를 동일한 규칙으로 학습해 깊이의 영향만 분리.
5. **초기화 요령**: 깊은 망은 초기화에 민감해, 얕은 구성 A를 먼저 학습한 뒤 그 가중치로 더 깊은 망의 첫 4개 conv와 마지막 3개 FC를 초기화했다. (논문은 Glorot 초기화로 사전학습 없이도 가능하다고 덧붙임)
6. **Scale jittering & dense evaluation**: 학습 시 짧은 변 S를 [256, 512]에서 무작위로 골라 리사이즈 후 224×224 크롭, 테스트 시 FC를 conv로 바꿔 전체 이미지에 dense하게 적용.

## 3. 아키텍처/방법

입력: 224×224 RGB (학습셋 평균 RGB를 뺌). 모든 conv 뒤에 ReLU. LRN은 성능 향상이 없어(A vs A-LRN) 이후 구성에서 제거.

### 3.1 구성 표

| 구성 | A (VGG-11) | B (VGG-13) | C (16, 1×1 포함) | D (VGG-16) | E (VGG-19) |
|---|---|---|---|---|---|
| 가중치 층 수 | 11 | 13 | 16 | 16 | 19 |
| Block1 (224→112) | 64 ×1 | 64 ×2 | 64 ×2 | 64 ×2 | 64 ×2 |
| Block2 (→56) | 128 ×1 | 128 ×2 | 128 ×2 | 128 ×2 | 128 ×2 |
| Block3 (→28) | 256 ×2 | 256 ×2 | 256 ×2 + 1×1 256 | 256 ×3 | 256 ×4 |
| Block4 (→14) | 512 ×2 | 512 ×2 | 512 ×2 + 1×1 512 | 512 ×3 | 512 ×4 |
| Block5 (→7) | 512 ×2 | 512 ×2 | 512 ×2 + 1×1 512 | 512 ×3 | 512 ×4 |
| Classifier | FC4096 – FC4096 – FC1000 – softmax (모두 동일) | | | | |

각 블록 끝에 2×2 max-pool(stride 2). 공간 크기: 224 → 112 → 56 → 28 → 14 → 7.
마지막 특징 맵은 512×7×7 = 25,088 차원.

### 3.2 파라미터 수

구성 A~E의 총 파라미터는 각각 약 133M, 133M, 134M, 138M, 144M.
대부분이 첫 FC(`25088×4096 ≈ 103M`)에 몰려 있다. 즉 **conv는 깊지만 가볍고, 파라미터 대부분은 FC에 있다**.
→ 후속 연구(GoogLeNet, ResNet)가 FC를 global average pooling으로 대체하는 동기가 된다.

### 3.3 학습 설정

- 미니배치 SGD + momentum 0.9, 배치 256, weight decay `5e-4`, 앞의 FC 2개에 dropout 0.5.
- 초기 learning rate `1e-2`, 검증 정확도가 정체되면 10배씩 감소(총 3회). 약 74 epoch.
- 랜덤 크롭 + 좌우 반전 + RGB 색 변형(AlexNet 방식) 증강.
- 수용 영역: 3×3 conv(stride 1)를 `n`개 쌓으면 `(2n+1)×(2n+1)`.

### 3.4 Dense evaluation

테스트 시 FC 3개를 각각 7×7, 1×1, 1×1 conv로 변환(FC→conv)하면 임의 크기 이미지에서 클래스 점수 맵(`h×w×1000`)을 얻고,
이를 공간 평균해 고정 길이 벡터로 만든다. 크롭을 일일이 뽑는 것보다 효율적이며, FCN(분할)의 전신이기도 하다.

## 4. 실험 결과 요약 (ILSVRC 기준)

- **깊이 효과**: 단일 스케일 평가에서 A(11층) → B(13) → D(16) → E(19)로 갈수록 오류율이 감소하고, 19층 부근에서 포화.
  A-LRN은 A보다 나아지지 않아 LRN이 무용함을 확인.
- **C vs D**: 1×1 conv(C)는 B보다 낫지만 3×3 conv(D)가 더 낫다 → 비선형성만으로는 부족하고 공간 정보 포착이 중요.
- **Scale jittering** 학습이 고정 스케일 학습보다 확실히 좋다.
- **멀티 크롭 + dense 결합 평가, 앙상블**로 추가 향상. 제출 앙상블의 top-5 test error는 약 7.3%, 제출 후 2개 모델(D, E) 앙상블로 약 6.8%.
- 다른 데이터셋(VOC, Caltech 등)으로 전이해도 강력한 범용 특징 추출기 → 이후 수년간 backbone의 표준(R-CNN 계열, 스타일 전이 등).

## 5. 의의 (앞뒤 논문과의 연결)

- **← AlexNet**: 큰 커널·큰 stride 대신 3×3 반복이라는 균일하고 단순한 설계로 깊이를 키움. "블록 반복" 철학은 ResNet, DenseNet으로 이어진다.
- **→ GoogLeNet(같은 해, 이번 주 2번째)**: 같은 대회 1위. 깊이를 늘리되 VGG만큼 무겁지 않게 하는 다른 해법(Inception, 1×1 병목, 파라미터 수 훨씬 적음).
- **→ BatchNorm / ResNet**: plain 구조로는 VGG-19 정도가 학습 가능한 한계에 가깝고, 이를 넘기 위해 BN, skip connection이 필요해진다.
- 단점: 파라미터·메모리·연산량이 크다. 하지만 구조가 단순해 feature extractor, perceptual loss 등으로 지금도 쓰인다.

## 6. 구현 노트

`implementation/model.py`는 구성 A/B/D/E를 `CFGS` 딕셔너리로 정의하고 하나의 `VGG` 클래스로 만든다(구성 C 생략).
- 논문에 없는 `batch_norm` 옵션 제공(기본 False).
- 사전학습식 초기화 대신 Kaiming 초기화 사용.
- `AdaptiveAvgPool2d`로 FC 입력 크기를 고정해 입력 해상도가 달라져도 동작(현대 torchvision 방식).
- `train.py`는 CIFAR-10(32×32)에서 VGG-11을 **BN 없음 vs 있음** 으로 비교한다. 작은 입력용으로 분류기 크기를 줄였다.
